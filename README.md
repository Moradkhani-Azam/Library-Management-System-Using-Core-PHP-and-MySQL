## Instructions: How to Run?

<p>
 
<h4>1.Download and install XAMPP.</h4>

<h4>2.Unzip the project file and head over to your XAMPP directory.</h4>
 
<h4>3.There you’ll find a folder naming “htdocs”. Inside the “htdocs” folder, paste the project folder (not the .zip one, but the extracted one).</h4>

<h4>4.Open your browser, Google Chrome or Mozilla Firefox. </h4>

<h4>5.Go to URL “http://localhost/phpmyadmin“. </h4>

<h4>6.Create a Database with the name library </h4>

<h4>7.Click on the “Import” tab and choose the database file (tables.sql) which is provided under the main. </h4>

<h4>8.After setting up all these, go to URL “http://localhost/[ library or ENTER_PROJECT_FOLDER_NAME_HERE ]“ </h4>

<h4>9.All the login password are '1234' and emails are in MySQL users table.</h4>
 
</p>
